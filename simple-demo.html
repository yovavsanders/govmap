Vue 3 Mixin Implementation

This implementation provides reusable functionality for both Vue 3's Options API and Composition API approaches.

✅ Implementation Complete! The mixin includes:
  • Computed Property: currentTimestamp - Real-time formatted timestamp
  • Methods: formatNumber(), validateEmail(), counter management
  • Lifecycle Hooks: mounted(), beforeUnmount() with proper cleanup
Options API + Mixin

Traditional Vue Mixin Approach

Features:

  • Drop-in mixin compatibility
  • Familiar this syntax
  • Easy migration from Vue 2
  • Automatic method binding
// Import and use the mixin import { sharedMixin } from './mixins/sharedMixin.js'; export default { mixins: [sharedMixin], computed: { // Use mixin functionality displayInfo() { return `${this.currentTimestamp} - ${this.formattedCounter}`; } }, methods: { handleClick() { this.incrementCounter(); const formatted = this.formatNumber(this.mixinCounter); console.log('Counter:', formatted); } }, template: ` <div> <p>{{ currentTimestamp }}</p> <p>{{ formattedCounter }}</p> <button @click="incrementCounter">Increment</button> </div> ` };
Composition API + Composable

Modern Vue Composable Approach

Features:

  • Better tree-shaking support
  • TypeScript-friendly
  • Explicit dependencies
  • Configuration options
// Import and use the composable import { useSharedFunctionality } from './composables/useSharedFunctionality.js'; export default { setup() { const { mixinCounter, currentTimestamp, formattedCounter, formatNumber, incrementCounter, validateEmail } = useSharedFunctionality({ enableTimestampUpdates: true, componentName: 'MyComponent' }); // Component-specific logic const doubleCounter = computed(() => mixinCounter.value * 2); const handleClick = () => { incrementCounter(); const formatted = formatNumber(mixinCounter.value); console.log('Counter:', formatted); }; return { currentTimestamp, formattedCounter, doubleCounter, handleClick }; }, template: ` <div> <p>{{ currentTimestamp }}</p> <p>{{ formattedCounter }}</p> <button @click="handleClick">Increment</button> </div> ` };
